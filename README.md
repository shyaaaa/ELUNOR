# ELUNOR ✨

### Beauty Intelligence, Reimagined

Elunor is an AI-powered beauty intelligence platform designed to explore beauty products, analyze consumer trends, and transform raw cosmetic data into meaningful insights.

Instead of creating another basic analytics dashboard, Elunor focuses on combining:

* data science
* AI-driven insights
* beauty industry intelligence
* modern luxury-inspired UI

into a single experience.

The project was built to simulate how a real-world AI beauty startup could analyze product ecosystems, customer behavior, pricing patterns, and brand performance.

---

# 🌸 Features

* AI-inspired beauty analytics dashboard
* Product exploration and search
* Category-based filtering
* Brand performance analysis
* Consumer trend insights
* Elegant Rhode-inspired UI/UX
* Interactive visualizations
* Data-driven beauty intelligence

# 🎨 UI Inspiration

The interface design takes inspiration from modern luxury beauty brands such as Rhode, focusing on:

* minimalism
* soft editorial aesthetics
* luxury-inspired typography
* clean layouts
* premium user experience

The goal was to make the platform feel less like a traditional dashboard and more like a modern AI beauty product.

# 💡 Why Elunor?

Most student data science projects focus only on models and analytics.

Elunor was built with a different vision:
to combine technical intelligence with product thinking, branding, UI design, and real-world user experience.

The project aims to demonstrate how AI can be applied creatively within the beauty and lifestyle industry.

# ▶️ Run Locally

Clone the repository:

```bash
git clone <your-repo-link>
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit app:

```bash
streamlit run app.py
```
